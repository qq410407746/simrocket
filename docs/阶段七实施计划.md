## 第一组：火箭设计与存档

1. 纯数据图纸：1–4个串联推进级与一个载荷，复用现有目录中的完整模块；图纸只存模块标识，不接收自定义物理参数。可替换、增删、排序、命名和保存。使用现有虚构器材的设计参数，不能称为实测硬件数据。设计器不增加没有质量依据的发动机替换或缩放。
2. 编译图纸时校验版本、名称、标识、级数；生成唯一级标识和独立定义。沿用各模块热学、几何、发动机与质量，组合结构限值取各来源最保守值。尺寸不一致提示尚无转接结构模型，阻止保存与飞行；载荷整流罩的原生宽肩构型允许。
3. 性能沿用物理层：质量求和；海平面推重比F/(mg₀)；各级Δv=g₀Isp ln(m₀/m₁)，分级扣除抛弃质量。理想Δv不是入轨保证；推重比不足给出警告，不擅自提高推力。
4. 自由飞行选择已保存图纸，Worker和渲染共用同一定义；任务仍固定原型号和发射场。图纸使用有版本且校验过的本地存储，可导入导出备份，容量受限，失败要明确反馈。
5. 飞行日志附带遥测采样与事件保存到IndexedDB，最多50次；打开历史记录后可拖动时间轴回看采样读数与曲线。旧日志无曲线时明确提示。此功能是遥测回看，不是三维状态重放，也不能恢复物理积分继续飞行。
6. 文档、浏览器验收、截图与中文阶段进展报告，提交并同步feature/001。

## 验收

- 单元测试：非法图纸/损坏存档/缺失模块/重复级标识/尺寸不兼容；模块重组不改变内置火箭；性能与分级质量一致；实际Simulation能用自定义火箭起飞。
- 持久化校验：未知版本、非有限采样、时间倒序、容量边界；回看边界与插值；存储失败有反馈，不产生虚假成功。
- 浏览器：设计→保存→刷新→选择→起飞；图纸导入导出；结束飞行→刷新→日志回看；旧任务菜单及语言切换回归。
- 每次提交前类型检查、ESLint、全部单元测试、生产构建；浏览器测试串行、trace关闭，截图SwiftShader与deviceScaleFactor=2。
