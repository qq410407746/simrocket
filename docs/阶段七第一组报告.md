# 阶段七第一组：火箭设计与存档

日期：2026-11-17。分支：`feature/001`。用户已确认进入阶段七，并选择优先火箭设计与存档。此报告覆盖第一组增量，阶段七整体仍在进行。

## 完成了什么

- 新增火箭设计室：从三种内置火箭复制模板，选择完整推进级、增删和调整顺序，配置载荷、命名、保存和复制图纸。支持1–4级，接口不兼容时拒绝；没有凭空添加零质量转接器。
- 实时显示总质量、高度、海平面推重比、逐级燃烧时间和真空理想Δv。复用原模块的发动机、质量、热学和结构参数；低推重比会警告，不会自动提高推力。
- 保存最多20份图纸，刷新后可用于自由飞行；支持JSON备份导入/导出。未知版本、坏数据、同标识不同内容、容量超限均明确拒绝。存储失败不修改已保存的内存状态。
- 自定义图纸编译出的同一份定义用于Worker、三维模型、HUD和飞行提示。任务模式仍固定原型号和发射场；原八任务评分没有改动。
- 飞行曲线及事件保存在IndexedDB，与最近50条日志对应。打开历史日志可以拖动时间轴、以1×/10×/100×回看，或导出遥测JSON。旧日志没有曲线时会说明，损坏档案不会进入读数界面。清空记录同时清理曲线。

## 验收

- 类型检查、ESLint、47个文件/824项单元测试、生产构建通过。
- 单元测试验证复制模板性能等价、内置定义隔离、重组质量与分级、重复模块唯一标识、坏图纸和备份、任务固定型号、存储失败、遥测边界及插值。自定义火箭在真实Simulation中耗料并起飞。
- 首轮11项相关浏览器测试全部通过（3.8分钟）：新图纸全流程、错误路径、原任务系统、四项语言回归与暂停机动规划。中间复测发现并修复了会话竞态；最终同样11项全部通过（3.9分钟），包含日志唯一性、时间范围非零与设置栏不重叠检查。
- 浏览器用按钮完成“晨光试验一号”图纸保存/刷新/选择/起飞，起飞质量14900 kg，飞行中实际质量下降；主动提前关机，飞行结束后刷新仍能回看曲线。该试验验证存档闭环，不是一次成功入轨或返回任务。
- 截图使用SwiftShader、deviceScaleFactor=2。没有GPU性能基准；本组未重复阶段六17.9分钟GEO全程，也没有把历史结果计作本轮通过。

## 发现并修正的问题

- 浏览器复测复现了旧Worker迟到消息串入新飞行的竞态：重启后会额外生成一条单点曲线日志。现每次新飞行先释放旧客户端，加入会话隔离单元测试，并要求浏览器日志恰好一条、回看时间范围非零。
- 旧HUD的三个查询点只认识内置型号，会把自定义火箭显示成默认火箭；已统一使用图纸解析入口。
- 不能用JSON深拷贝完整物理定义：旧返回舱的无限横向载荷阈值会丢失。图纸只存标识，编译时结构化克隆模块并保留原物理参数。
- 遥测展开后的长内容被菜单弹性布局压缩，设置栏会覆盖读数。已让内容和设置栏保持自然高度，通过外层滚动容纳，并增加防重叠断言。
- 旧语言测试要求全页无汉字，与新增功能必须中文的要求冲突。明确排除新增中文区域，继续检查旧任务、仪表和日志元数据的英文；没有删除旧语言断言。
- 新增档案写入、读取和清空串行，避免排队中的旧写入晚于清除完成后重新出现。

## 没有完成或没有验证的

- 设计器组合的是已有完整模块，不是自由绘制贮箱或独立替换发动机；只支持同接口直径，尚无转接结构、更多硬件参数或技术树。
- 遥测回看不是三维飞行重放，也不能继续物理积分。中途物理存档、三维回放仍未实现；采样间是线性估读，精确峰值以物理统计为准。
- 图纸可导入恢复；遥测JSON目前只支持导出分析，不提供曲线导入，也没有云同步。设置和任务进度仍为LocalStorage，遥测为IndexedDB。
- 浏览器数据清除会丢失本地存档；存储权限与配额由浏览器决定。图纸配额失败已做故障注入，IndexedDB跨标签页升级/配额故障尚未专门注入测试。
- 真人试玩、真实GPU、Safari和触摸设备没有验证。自动驾驶、专家姿态/J2、更多画面效果及完整设置仍未完成。

## 需要用户确认的事项

原先的自动滚转、任务内换火箭/发射场、旧火箭Δv收紧没有新增答复，本组继续保持现状。设计器的模块粒度、接口约束和回看操作等待实际试玩反馈；这些不阻止已授权的阶段七开发。
