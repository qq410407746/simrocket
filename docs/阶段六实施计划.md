## 物理定义与推导

- 沿用已有通用变量开普勒传播。解析传播仅处理二体真空平动，不把它当作有阻力或有推力积分器。模型的大气顶为 1000 km；椭圆穿越半径 R+h 时由 cosν=(p/r−1)/e 求下降交点，再用 M=E−e sinE 和 n=√(μ/a³) 得下一边界时间。
- 机动基向量与已有指向约定一致：P=v/|v|，N=(r×v)/|r×v|，R=P×N。Δv=ΔvP·P+ΔvR·R+ΔvN·N。预览先传播至节点，再对速度加脉冲；实际飞行使用推力、质量流量和姿态积分，必须显示有限燃烧误差。
- 活力公式 v²=μ(2/r−1/a)。霍曼转移 a=(r1+r2)/2，第一次 Δv=√(μ(2/r1−1/a))−√(μ/r1)，第二次为目标圆轨道速度减转移远地点速度。倾角变化合并燃烧 Δv=√(v1²+v2²−2v1v2 cosΔi)；只能在目标轨道面交线上消除倾角。
- 同步半径 r同步=(μ/ω地球²)^(1/3)，周期为 2π/ω地球，不能用太阳日 86400 s。GSO 只判断周期；GEO 还检查顺行赤道、小偏心率以及覆盖一个恒星日的星下点经度摆幅，避免只看两端造成周期混叠。
- 地面轨迹：各预测点使用各自时刻 θ(t)=θ0+ωt 的 ECI→ECEF 转换，再求经纬度；跨 ±180° 经线断开。
- 部署延用质量、质心与分离冲量守恒；不得通过直接改轨道完成任务。
